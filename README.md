# ✅ Validação de Formulário - Projeto EBAC

Este projeto é uma atividade prática do curso da **EBAC**, com foco em validação de formulários utilizando **HTML**, **CSS** e **JavaScript**. O sistema verifica se o valor inserido no **Campo B** é maior que o valor do **Campo A** e exibe uma mensagem informando se o formulário é válido ou inválido.

## 💡 Funcionalidades

- Validação de entrada de dados em tempo real
- Prevenção do envio do formulário caso a validação falhe
- Exibição de mensagens dinâmicas (sucesso ou erro)
- Manipulação do DOM com JavaScript puro
- Estilização personalizada para feedback visual

## 🧪 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
